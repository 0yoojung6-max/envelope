# 봉투 활동 웹앱 (교사 제어 · 길라잡이 AI 토론 · 타이머 · 우리 반 활동 보드)

## 폴더 구성

```
site/
├─ index.html      예술 철학자 테스트 (기존 그대로)
├─ envelope.html   봉투 활동 앱 (교사 화면 + 모둠 화면)
├─ api/chat.js     길라잡이(AI) 서버 함수 (API 키는 여기서만 사용)
├─ package.json    서버 함수 실행 설정
└─ README.md
```

## 활동 흐름

안건 → 봉투 1 → 봉투 2 → **잠정 결론 입력 → 길라잡이와 토론(채팅)** → **최종 결론을 우리 반 활동 보드에 올리고 서로 공감·댓글**

| 기능 | 동작 |
|---|---|
| 교사 제어 | 교사가 "○○ 열기"를 눌러야 모둠 화면에 다음 단계가 열림 |
| 입력 검증 | 이유가 15자 미만이거나 "ㅋㅋㅋ", "뿅뿅뿅", 기호만 있는 경우 "모둠의 이유를 조금 더 자세하고 구체적으로 작성해 주세요!" 알림과 함께 제출 불가 |
| 길라잡이 | 잠정 결론(점수+이유)을 읽고 모둠의 표현을 짚어 반대편 질문을 던지고, 모둠이 답하거나 반론하면 그 말을 이어받아 꼬리 질문으로 대화를 이어 감 (반론 최대 4회) |
| 타이머 | 기본 2분, 교사 화면에서 ±10초 조절·시작·일시정지·리셋, 모든 모둠 화면에 실시간 표시 |
| 우리 반 활동 보드 | 모둠이 최종 결론을 올리면 0~10점 줄 위에 모둠 위치가 찍히고 카드가 붙음. 모든 모둠과 교사 화면에 실시간으로 같은 보드가 보이고, 다른 모둠 카드에 공감과 댓글을 남길 수 있음. 자기 카드는 고치기 가능 |
| 교사 현황판 | 모둠별 잠정 점수, AI와 주고받은 횟수와 마지막 메시지, 최종 점수가 실시간으로 모임 |

## 접속 주소

| 기기 | 주소 |
|---|---|
| 모둠 태블릿 (모두 같은 주소) | `https://내사이트.vercel.app/envelope.html` → 첫 화면에서 모둠 번호 선택 |
| 교사 화면 | `https://내사이트.vercel.app/envelope.html#teacher` |

학생용 QR은 `envelope.html` 주소 하나로 만들면 됩니다. 모둠 번호를 잘못 골랐다면 화면 위 **모둠 다시 고르기**를 누르세요. 교사 화면은 학생 첫 화면에 나타나지 않으니, 교사용 노트북에서 `#teacher` 주소를 즐겨찾기에 넣어 두세요.

---|---|
| 교사 화면 | `https://내사이트.vercel.app/envelope.html#teacher` |
| 1~4모둠 태블릿 | `.../envelope.html#group-1` ~ `#group-4` |

모둠별 주소로 QR을 만들어 두면 태블릿이 바로 그 모둠 화면으로 들어갑니다.

## 설정 1. AI 키 (필수, 하나만)

Vercel 프로젝트 → **Settings → Environment Variables**에 아래 중 하나를 넣고 **Redeploy** 하세요.

| 쓰는 서비스 | 환경 변수 | 모델 바꾸기 (선택) |
|---|---|---|
| OpenAI | `OPENAI_API_KEY` | `OPENAI_MODEL` (기본 `gpt-4o-mini`) |
| Gemini | `GEMINI_API_KEY` | `GEMINI_MODEL` (기본 `gemini-flash-latest`) |
| Claude | `ANTHROPIC_API_KEY` | `ANTHROPIC_MODEL` (기본 `claude-haiku-5-5`) |

키가 여러 개라면 `AI_PROVIDER`에 `openai`, `gemini`, `anthropic` 중 하나를 적어 고르세요. 각 서비스의 모델 이름은 바뀔 수 있으니 콘솔에서 현재 이름을 확인해 넣는 것을 권합니다.

**키를 envelope.html에 직접 적지 마세요.** 키는 서버 함수 안에서만 쓰입니다.

AI의 말투, 사용할 사실 카드, 응답 형식은 `api/chat.js`의 `SYSTEM_PROMPT`에서 고칩니다. AI는 여기 적힌 사실 밖의 내용을 지어내지 않도록 지시되어 있습니다.

## 설정 2. 실시간 연동 Firebase (교사 제어·타이머에 필요)

1. https://console.firebase.google.com 에서 프로젝트 생성
2. **Realtime Database → 데이터베이스 만들기 → 테스트 모드로 시작**
3. **프로젝트 설정 → 내 앱 → 웹 앱(</>) 추가** 후 `firebaseConfig` 복사
4. `envelope.html` 위쪽 `CONFIG.firebase`에 붙여 넣기 (`databaseURL`이 꼭 있어야 함)

Firebase가 없거나 연결이 끊기면 모둠 화면에 "○○ 열기" 버튼이 나타나 스스로 넘어가고, 타이머는 교사 화면에만 표시됩니다.

## 설정 3. 우리 반 활동 보드

따로 설정할 것이 없습니다. Firebase(설정 2)만 연결되어 있으면 보드가 모든 기기에서 공유됩니다. 댓글이나 공감을 끄고 싶으면 `CONFIG.board`에서 `comments`, `likes`를 `false`로 바꾸세요. Firebase가 없으면 각 모둠 화면에는 자기 모둠의 글만 보입니다.

## 설정 4. 배포

`api/` 서버 함수가 있으므로 GitHub 저장소에 올려 Vercel에서 **Import** 하거나, 폴더에서 `npx vercel` 로 배포하세요.

## 리허설 체크리스트

- [ ] 교사가 "봉투 1 열기"를 누르면 모든 모둠에 열리는가
- [ ] 타이머 ±10초, 시작, 일시정지, 리셋이 모둠 화면에도 똑같이 보이는가
- [ ] "뿅~", "ㅋㅋㅋ"처럼 입력하면 알림이 뜨고 넘어가지 않는가
- [ ] AI가 점수 0, 5, 10과 다양한 이유에 맞게 답하는가, 사실을 지어내지 않는가
- [ ] 모둠의 반론을 길라잡이가 읽고, 그 표현을 짚어 꼬리 질문을 하는가
- [ ] 한 모둠이 결론을 올리면 다른 모둠과 교사 화면의 보드에 바로 뜨는가, 공감·댓글이 되는가
- [ ] 리허설 뒤 교사 화면 **새 수업으로 초기화**(두 번 누르기)
